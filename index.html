App "Quanto Tá?"

Problema

O mesmo produto custa preços diferentes em cada mercado, e o consumidor não tem como comparar.

O que construí

App mobile que lê o QR Code da nota fiscal (NFC-e), extrai produtos e preços da SEFAZ e compara mercados, monta lista de compras e calcula o custo de pratos. Aceita também foto, XML, link e notas em lote. Funciona offline e sincroniza depois.

Resultado

App completo, feito do zero com Claude Code e testado no celular. Banco com acesso por linha (RLS) e CPF guardado apenas como hash.

Claude Code · React Native / Expo · Supabase · PostgreSQL

Descorruptor de Banco de Dados

Problema

Bancos de clientes corrompidos travavam a operação e podiam gerar multas da SEFAZ. A recuperação dependia de investigação manual.

O que construí

Programa que analisa o banco com apoio de IA, identifica o que está corrompido e conduz a recuperação.

Resultado

Já evitou possíveis multas da SEFAZ, com economia de dezenas de milhares de reais para clientes reais.

IA para análise de dados · bancos de dados

Dashboard de gestão do suporte

Problema

Os dados de atendimento estavam espalhados e a gestão não enxergava a operação do suporte.

O que construí

Dashboard completo em Power BI que centraliza pesquisa de satisfação (satisfeito, insatisfeito, não respondido), assunto dos tickets, metas dos agentes e alerta de quem está perto da meta.

Resultado

Alimenta os relatórios estratégicos que a alta gestão usa para acompanhar o suporte.

Power BI · modelagem de dados · indicadores

Orquestração de IA

Problema

Usar o modelo mais caro para toda tarefa gasta tokens e limite à toa.

O que construí

Sistema com hooks, subagentes e MCP no Claude Code. O Laya, um classificador que roda na minha GPU, faz a triagem de erros e roteia as tarefas por custo entre Claude e Gemini.

Resultado

Resposta em cerca de 40 ms por chamada, menos tokens gastos e uso do modelo mais forte só onde ele decide.

Claude Code · Hooks · MCP · Gemini · Python / PyTorch
